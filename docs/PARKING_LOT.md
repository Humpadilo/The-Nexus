# Parking Lot

These ideas are intentionally not part of the current sprint. Recording them preserves context without turning them into commitments. Move an item into a specification and sprint only after its goal, risks, permissions, and acceptance criteria are understood.

## AI

- Optional AI-assisted explanation of recurring health findings.
- Multiple model providers with local fallback behavior.
- Confidence calibration based on historical outcomes.

## Automation

- Detection of duplicated or conflicting automations.
- Suggested automation simplification.
- Automation dependency and trigger visualization.

## Dashboards

- A household overview dashboard.
- Role-specific views for maintenance, safety, and activity.
- Timeline view for snapshot and watcher events.

## Occupancy

- Privacy-preserving occupancy inference.
- Room presence confidence.
- Occupancy-aware maintenance reports.

## Voice

- Voice questions about system health.
- Spoken explanations of approved recommendations.
- Voice approval with explicit confirmation safeguards.

## Sensors

- Sensor quality and stale-data detection.
- Battery replacement planning.
- Calibration and unit consistency suggestions.

## Experimental

- Laboratory simulation of proposed changes.
- What-if testing for house modes.
- Historical replay of state observations.

## Developer Experience

- Fixture generator from anonymized snapshots.
- Home Assistant version compatibility matrix.
- Automated app installation smoke tests.
- Documentation consistency checks.
- Development dashboard for module health.

## Deferred integrations and assumptions

- SmartThings integration or migration.
- House-mode model.
- External cloud services.

These are not present in the current codebase and require specifications before implementation.
